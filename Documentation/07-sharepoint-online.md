# Task 07 - SharePoint Online

## Objective

Configure and manage a SharePoint Online Team Site.

The goal was to understand how SharePoint is used to store, organize, share, and manage company files.

## Environment

- Microsoft 365 Tenant: `kozika.online`
- SharePoint Site: `kozika-it-sharepoint`
- Site Type: Private
- SharePoint Domain: `kozika12.sharepoint.com`
- Site Address: `/sites/kozika-it-sharepoint`

## 1. Create SharePoint Team Site

Created a new SharePoint Team Site from the SharePoint Admin Center.

The original name `Kozika IT` could not be reused because an existing Microsoft 365 Group with the same alias already existed.

A different site name was used:

`kozika-it-sharepoint`

The site was created successfully as a Private group.

## 2. SharePoint Home Page

Reviewed the SharePoint Team Site home page.

Important components included:

- Home
- Documents
- Pages
- Notebook
- Site contents
- Activity
- News

A Team Site can be used to connect a team with shared content, information, and applications.

## 3. Document Library

Opened the default **Documents** library.

Created the following folders:

- `Infrastructure`
- `Helpdesk`
- `Policies`

These folders provide a simple structure for organizing IT department documents.

## 4. File Management

Inside the `Infrastructure` folder, created a Word document for infrastructure documentation.

File created:

`Infrastructure-Documentation.docx`

The file was used to practice working with documents inside a SharePoint Document Library.

## 5. Site Permissions

Reviewed:

**Settings → Site permissions**

The site contains SharePoint groups for managing access:

### Site Owners

- Permission: Full Control

### Site Members

- Permission: Edit

### Site Visitors

- Permission: No Control

The site group contained:

- Ahmed Hassan
- Sara Ali

This demonstrates the basic SharePoint permission model.

## 6. File Sharing

Reviewed the SharePoint **Link Settings** for the infrastructure document.

Available sharing options included:

### People in kozika

Users inside the organization can access the link.

An organization account is required.

### Only people with existing access

Only users who already have permission can use the link.

### People you choose

Access can be shared with selected people.

Additional permissions included:

- Can edit
- Can view
- Link expiration date

The sharing settings were reviewed without creating unnecessary external sharing.

## 7. Version History

Reviewed the **Version History** option for SharePoint files.

Version History is used to view previous versions of a document and recover an earlier version when required.

## 8. Enterprise Scenario

The SharePoint site represents a central document location for the IT department.

Example structure:

- `Infrastructure` → infrastructure documentation
- `Helpdesk` → support procedures and troubleshooting documents
- `Policies` → IT policies and procedures

SharePoint can provide centralized document storage with controlled access and collaboration.

## 9. Key Concepts Learned

### SharePoint Team Site

A workspace used by a team to manage shared content and information.

### Document Library

A central location for storing and managing files.

### Folder

Used to organize documents inside a library.

### Site Permissions

Control who can access and manage the SharePoint site.

### File Sharing

Controls how individual files can be shared with users.

### Version History

Keeps previous versions of documents and allows recovery of earlier versions.
